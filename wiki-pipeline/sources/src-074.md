## Summary

Moral Fabric's employee-facing IT security checklist: **one-off checks** (devices, passwords, policy sign-off) and **recurring checks** (monthly file hygiene and patches, quarterly MFA/access and password-manager reports, annual policy re-read and phishing quiz). EU/NL-aware framing (AVG mention for unencrypted lost devices). Operational baseline for user-facing IT at first hires — identity, password manager, MFA, device hardening, and signed security policy.

## Notable claims

- Only supported OS versions with automatic updates; screen lock ~5 minutes; disk encryption on all work devices
- All passwords in a password manager; purge from browsers and other stores; generated strong passwords (≥14 chars)
- SSO preferred, MFA/2FA on all business accounts
- Sign information security policy — record of who was informed
- Recurring: monthly downloads/desktop/recycle hygiene + patch check; quarterly device-policy compliance + MFA check + password-manager security report; yearly policy re-read + phishing quiz + Google Security Checkup
