## Summary

OpenOrg operator guide replacing annual reviews with a continuous rhythm: team OKRs aligned to company objectives, real-time feedback, weekly 1-on-1s with shared notes, monthly goal reflection, and **quarterly lightweight check-ins** (self-reflection + manager prep from 1-on-1 notes + ~45-minute conversation). Recommends running the whole process manually in Notion or Google Docs for **one full quarter** before buying HRIS. Includes lean startup calibration (~90 minutes) and SBI feedback scripting.

## Notable claims

- Performance management = goal setting + continuous feedback + lightweight check-ins — weak link breaks the system
- Quarterly check-in should have zero surprises; summarizes 1-on-1 feedback
- Employee self-reflection on wins, challenges, next-quarter focus; manager prepares from 1-on-1 notes
- Weekly 1-on-1 is the engine room — not a status update; capture brief notes in shared doc
- Monthly macro check on OKR progress without necessarily another meeting
- Start with Notion/Google Doc templates; run manually one quarter before automating
- Lean calibration (~90 min) so ratings mean the same across teams
- First-time critical feedback at annual review means the system already failed
